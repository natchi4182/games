## 作り方
- `fight3d.html?studio` を開くと、1体ずつ背景なしでポーズを撮れる撮影モードになる（`window.__studio.snap(設定)`）。
- `tools/st.js` が `tools/s3.json` のポーズ設定で撮影し、`tools/compose.js` がセリフを入れてLINEの規格に合わせる（Playwright で実行。パスは作成環境のもの）。
