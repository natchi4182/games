## 作り方
- `fight3d.html?studio` を開くと、1体ずつ背景なしでポーズを撮れる撮影モードになる（`window.__studio.snap(設定)`）。
- 撮影の設定に `props` を書くと、プレゼント・ツリー・サンタ帽・鈴を置ける（手・頭・トナカイの背中に付けられる）。
- `tools/st.js` が `tools/s3.json`（01〜16）と `tools/s5.json`（17〜24）のポーズ設定で撮影し（20 はサンタとトナカイの2枚を重ねて1枚にする）、`tools/compose.js` がセリフを入れてLINEの規格に合わせる（Playwright で実行。パスは作成環境のもの）。
