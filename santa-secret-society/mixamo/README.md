# S.A.N.T.A. 用 Mixamo モーション（2026-11-25 取得）

設定はすべて FBX Binary・Without Skin・30fps・Keyframe Reduction none。キャラは Mixamo 標準の骨（CH36）。
In Place があったもの（walk・mutant_walk）はオン。

| ファイル | Mixamo の名前 | 中身 |
|---|---|---|
| idle.fbx | Fighting Idle | ボクシングの構え（待機） |
| walk.fbx | Walking（Boxing Advancing Forward） | 構えたまま前へ（In Place） |
| punch.fbx | Boxing（Leading Hand Jab） | 前の手のジャブ |
| kick.fbx | Mma Kick（Roundhouse） | 回し蹴り |
| guard.fbx | Center Block（High） | 顔の前のガード |
| hit.fbx | Head Hit（Medium, Right Punch） | 頭に攻撃を受ける |
| ko.fbx | Knocked Out（Falling To Back） | 仰向けにダウン |
| win.fbx | Victory（Boxing Win） | 両手を上げる勝利 |
| jump.fbx | Jumping（From Action Idle） | その場ジャンプ |
| special_santa.fbx | Throw（Standard Pose） | 物を投げる（プレゼント） |
| special_blackruf.fbx | Standing 2H Magic Area Attack 02 | 両手でためて前へ放つ（闇の玉） |

後退は walk を逆再生する想定。専用の後退が要るなら Boxing の「Step Backward」がある。
