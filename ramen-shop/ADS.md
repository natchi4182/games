# らーめん開業日誌 — 広告と有料会員の設計

無料で遊べる Web アプリとして公開し、広告収入につなげるための設計メモ。
- 公開先：fly.io（手順は DEPLOY.md）
- 広告：Google AdSense の Web ゲーム向け広告（H5 Games Ads / Ad Placement API の `adBreak`）
- **ゲーム側は組み込み済み。** `index.html` の `ADS_CONFIG.client` にパブリッシャーIDを入れると本物の広告に切り替わる。空のままなら広告は読み込まない
- URL の末尾に `#adpreview` を付けると、ID がなくてもダミー広告で配置と頻度を確かめられる

## 基本方針
- 広告は「プレイヤーが自分で選んだ大きな行動の前に1回」を中心にする（見返りのある広告）。毎日の営業や修行の1週ごとには出さない
- 区切りの広告（月次決算のあと）は、遊び始めて15分は出さない。前回の広告から3分以内も出さない
- 伝説の評論家の審査など、結果を左右する場面には広告を絡めない（広告を見れば有利になる、とはしない）
- 広告なし会員（100円の買い切り）は、すべての広告枠を飛ばす

## 広告枠（ゲームに組み込み済み）

| 枠 | 出る場面 | 種類 | 頻度の目安 |
|---|---|---|---|
| 修行を飛ばして開業 | 開業画面で「平均的な修行経験で開業」を選んだとき | 見返りあり | 1ゲームに1回 |
| 最上級の素材を初めて仕入れる | スープ・麺・チャーシューを初めて最上級にするとき | 見返りあり | 1ゲームに最大3回 |
| 求人を出して雇える人数を増やす | 仕込みタブの「求人を出す」（10万円・各+1、最大2回） | 見返りあり | 1ゲームに最大2回 |
| 新メニューの試作を始める | メニュー開発の「試作する」 | 見返りあり | 1品ごとに1回 |
| 移転を契約する | 移転の契約時 | 見返りあり | まれ |
| 新店舗を契約する | 支店の契約時 | 見返りあり | まれ |
| 月次決算のあと | 損益計算書を閉じたとき | 区切り | 月1回（開始15分は出さない・3分以内に連続しない） |

## 広告の動き（AdSense 接続時）
- **見返りあり**：行動のボタンを押すと「広告を見て進む／やめる」が出る。最後まで見たら行動に進み、途中で閉じたら行動はしない。広告が用意できない・回数制限などのときは、ゲームを止めずにそのまま進める
- **区切り**：月次決算を閉じたあとに `next` 型の広告。遊び始めて15分と前回から3分以内は出さない（AdSense 側にも頻度の目安 180秒 を渡している）
- ゲームに音はないので `sound:'off'`、広告は事前に読み込む（`preloadAdBreaks:'on'`）

## あえて広告を入れない場所
- **「修行から始める」と「経験ゼロで開業」**：修行や素人スタートは遊びそのもの。ここで広告を出すと、遊び始める前に離れる人が増える
- **営業中・日報・修行の毎週**：頻度が高すぎて、遊びのテンポを壊す
- **伝説の評論家の審査・挫折の場面**：物語の山場。広告で水を差さない

## 本番に向けてオーナーにお願いしたいこと
1. **独自ドメインの取得**：AdSense は自分が持っているドメインでないとサイトを登録できない可能性が高い（`*.fly.dev` は不可の見込み）。fly.io への接続方法は DEPLOY.md
2. **AdSense の審査と、Web ゲーム向け広告の申し込み**：審査に通ったらパブリッシャーIDを `ADS_CONFIG` に入れ、`ads.txt` を置く
3. **広告なし会員（100円）の決済**：決済サービスの選定と登録。静的サイトなので、購入後に発行するコードを入力してもらう方式などを検討する（未着手）
4. ~~プライバシーポリシー~~ → **済（2026-10-18）**：MAWARU と同じ方針（運営 AirIo Creative・メール・Instagram）で `privacy.html` を書き直し、`terms.html`（利用規約）を追加。ゲーム画面の下に両ページとお問い合わせへのリンクを置いた
5. **EU など海外向け**：欧州の利用者に広告を出す場合は同意管理（CMP）の設定が要る。日本向けに限るなら AdSense 側で地域を絞る方法もある

いずれも外部サービスへの登録と費用が関わるため、オーナーの判断が出るまで進めない。

## 進め方（現在地：2026-10-18）
| 段階 | 内容 | 状態 |
|---|---|---|
| 1 | 規約・ポリシー・問い合わせ先の掲載 | 済 |
| 2 | 独自ドメインの取得と fly.io への接続（DEPLOY.md の 2） | オーナーの判断待ち（まだ決めない） |
| 3 | AdSense にサイトを登録して審査（ドメインが要る） | 2 のあと |
| 4 | Web ゲーム向け広告（H5 Games Ads）の申し込み | 3 と並行可。ベータで承認は保証されない |
| 5 | パブリッシャーIDを `ADS_CONFIG` に入れ、`ads.txt` を置いてデプロイ | 3・4 のあと（こちらで対応） |

- 審査用の AdSense アカウントは、MAWARU で使うものと同じアカウントに「サイトを追加」する形でよい（1つの人に1アカウントが原則）
- H5 Games Ads が通らなかった場合の代わり：ゲーム画面の外（下）に通常のディスプレイ広告を1枠だけ置く案。見返り広告は使えなくなる
