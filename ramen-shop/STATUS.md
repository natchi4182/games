# らーめん開業日誌 — STATUS

## いまの到達点（遊べること）
- `index.html` 1枚でブラウザから遊べる経営シミュレーション（ビルド不要）
- 毎朝、仕込み量・価格・素材・営業時間・シフトを決め、営業の様子を店内アニメで見る。日報・月次決算・ランダムイベントあり
- 最終目標「伝説のラーメン屋」までの5段階：開業1周年 → 行列店 → 一国一城 → 名店 → 伝説（評論家の審査あり）。期限はない
- 本店の移転（立地・広さを変更）と支店展開（店長を雇う・銀行融資・閉店）、繰上げ返済
- 経営診断：「あなたの経営は『○○型』です。このままで本当に満足ですか？」。6軸評価、S〜Dの総合評価、次の一手を表示。月次決算と目標達成時にも出る
- 開業前の修行（選択制・8〜24週）：毎週の過ごし方を選び、腕前・経営手腕・人脈・師匠の信頼・貯金を育てる。結果が開業時のスタート地点になる（味・原価・疲れにくさ・融資審査・知名度・店長候補の質・開業資金）。信頼80以上で暖簾分け、まれに秘伝の技
- 難易度「のんびり／リアル」。開業時に3ステップの説明。毎朝「親方のひとこと」が状況に合わせて助言し、仕込み量の目安をワンタップで設定できる（隠すこともできる）
- メニュー開発：二本目の看板麺・まぜそば・つけ麺・チャーハン・お子さまらーめん・ベジらーめん・期間限定麺。試作して品書きに載せる。品数が増えるほど客層は広がるが、評価・提供速度・疲労にマイナス。専門店か総合店かを選ぶ
- 経営診断に「メニュー迷走型」「一点突破型」を追加。月次決算に店主の生活費（月30万円）を計上
- 進み具合は localStorage に自動保存。旧バージョンのセーブも引き継げる
- ヘッドレスブラウザで自動プレイしエラーなし（500日・支店2店・移転・目標4まで。メニュー開発あり／なし、難易度別に330日ずつ）
