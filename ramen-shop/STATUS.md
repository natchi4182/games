# らーめん開業日誌 — STATUS

## いまの到達点（遊べること）
- `index.html` 1枚でブラウザから遊べる経営シミュレーション（ビルド不要）
- 毎朝、仕込み量・価格・素材・営業時間・シフトを決め、営業の様子を店内アニメで見る。日報・月次決算・ランダムイベントあり
- 最終目標「伝説のラーメン屋」までの5段階：開業1周年 → 行列店 → 一国一城 → 名店 → 伝説（評論家の審査あり）。期限はない
- 本店の移転（立地・広さを変更）と支店展開（店長を雇う・銀行融資・閉店）、繰上げ返済
- 経営診断：「あなたの経営は『○○型』です。このままで本当に満足ですか？」。6軸評価、S〜Dの総合評価、次の一手を表示。月次決算と目標達成時にも出る
- 開業前の修行（選択制・最低1年〜最長5年、1ターン＝1週間。4週・13週まとめて進めることもでき、昇格や出来事があると止まる）：昼は店での仕事（洗い場→仕込み→麺上げ→スープ番→店長代理と昇格）への向き合い方、夜は自分の時間（スープ研究・勉強・食べ歩き・付き合い・夜バイト・休む）を選ぶ。腕前・経営手腕・人脈・師匠の信頼・貯金が開業時のスタート地点になる。「心」が尽きると挫折して修行を辞める（ゲーム終了）。信頼80以上・2年以上で暖簾分け
- 才能：9種類（絶対味覚・湯切りの名手・段取り上手・目利き・愛想のよさ・人たらし・研究家・倹約家・不屈の心）。何が芽生えるかは秘密で、条件の6割で「予感」の一文だけが出て、満たした週に判明する。独立時に修行2年以上で1つ、4年以上で2つ選べる。効果は控えめ
- 修行中のビジョンと葛藤：「どんな職人になりたいか」「どんな店を持ちたいか」「師匠の味か自分の味か」を選ぶ場面、「自分には才能がないのでは」と悩む場面、ビジョンと日々がずれた時の葛藤。選んだビジョンは修行中の伸び方と開業後の小さな効果に反映し、経営診断で「夢に近づいているか」を示す
- 修行なしの開業は2種類：平均的な修行経験（腕前4.0・経営手腕1.5・人脈1.5）と経験ゼロ（ハード。味が落ちてブレる・提供が遅い・疲れやすい・融資審査が厳しい。腕前5で不利が消える）
- 難易度「のんびり／リアル」。開業時に3ステップの説明。毎朝「親方のひとこと」が状況に合わせて助言し、仕込み量の目安をワンタップで設定できる（隠すこともできる）
- メニュー開発：二本目の看板麺・まぜそば・つけ麺・チャーハン・お子さまらーめん・ベジらーめん・期間限定麺。試作して品書きに載せる。品数が増えるほど客層は広がるが、評価・提供速度・疲労にマイナス。専門店か総合店かを選ぶ
- 経営診断に「メニュー迷走型」「一点突破型」を追加。月次決算に店主の生活費（月30万円）を計上
- 進み具合は localStorage に自動保存。旧バージョンのセーブも引き継げる
- ヘッドレスブラウザで自動プレイしエラーなし（500日・支店2店・移転・目標4まで。メニュー開発あり／なし、難易度別に330日ずつ）
