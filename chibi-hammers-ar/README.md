# ちびハンマーズ AR

大きなハンマーを持った小さなかわいいやつら（ちびハンマーズ）が、
ハンマーを**オートで**振り回して荒地や廃墟をこわし、**整地**していくスマホ向け AR3D ゲームです。

最初にカメラでまわりの景色を撮影すると、その写真を解析して荒地・廃墟の盤面をデザインします。

## 遊び方

1. 「はじめる」→ カメラでまわりを撮影（📷）。写真を選ぶ（🖼️）／おまかせ（🎲）でも OK
2. 写真から作られた「荒地レポート」とマップを確認して「整地スタート！」
3. ちびたちが勝手にハンマーを振ってこわしていきます
   - がれき・廃屋を**タップ** → そこを集中攻撃
   - ちびを**タップ** → 応援（しばらくスイングが速くなる）
   - こわすとコイン → 「なかま」「パワー」「スピード」を強化
   - ゲージがたまったら「フィーバー」でハンマーが金色に！
4. 整地率 100% でクリア。芝生とお花が咲いて次のレベルへ

## 写真 → 荒地のデザイン

撮影画像を 8×8 マスに分割し（写真の上 = 盤面の奥）、マスごとの特徴で置くものを決めます。

| 写真の特徴 | 置かれるもの |
| --- | --- |
| ごちゃごちゃ（エッジが多い）＋暗い 2×2 | 廃屋 |
| エッジ多め・暗い / 明るい | 崩れた壁・廃材 / がれき |
| 緑が多い | 草むら・枯れ木 |
| なめらかで明るい | 小石 |

さらに、写真の色を k-means で抽出したパレットで素材を色付けし、
写真そのものをくすませたテクスチャを廃墟の壁に貼り、空・地面の色からライティングを合わせます。

## AR 表示

- **床トラッキング（iPhone など、ジャイロ＋カメラがある端末）**: 床やテーブルにカメラを向けてタップすると、そこに荒地を置きます。
  床の模様の点を追いかけて（ピラミッド Lucas-Kanade オプティカルフロー）、カメラの位置と向きを毎フレーム計算するので（6DoF）、
  スマホを持って動いても荒地が床に貼り付いたままになります。ジャイロは回転の予測と傾きの補正に使います。
  背景の映像も WebGL で描き、3D とコマずれしないようにしています。
  無地の床など模様が少ない場所では追跡できず、ジャイロだけの追従になります（画面に案内が出ます）。🎯 で置き直せます。
- **WebXR（対応端末のみ）**: Android Chrome など `immersive-ar` 対応端末では「床に置いて本格AR」で、端末の AR 機能で床を検出して置けます。
- **ジャイロのみ / PC**: 位置は追わず向きだけ合わせます。ジャイロが無い PC ではドラッグで視点を回せます。

床を認識できるモード（床トラッキング / WebXR）では、ジオラマの土台を出さずに**自分の部屋の床に直接**荒地を重ねます。

- 壊したマスは汚れが拭き取られて、本物の床がピカピカに見えてきます
- 初期サイズは実物大（床トラッキングで約 1.6m 四方、WebXR で約 1.2m 四方）。ピンチ / ＋－で変更できます
- **歩いて監督**：スマホを持って近づくと、足もと（黄色い輪）の近くにいるちびが張り切って 1.5 倍速で働きます

共通: 画面の真ん中（スマホを向けた場所）の近くのがれきを、ちびたちが優先して狙います。ちびやがれきの影が本物の床に落ちます。

## 起動方法

ビルド不要の静的サイトです（three.js は `vendor/` に同梱）。カメラを使うため **HTTPS**（または localhost）で配信してください。

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

GitHub Pages でリポジトリのルートを公開すれば、スマホからそのまま遊べます。
