# ちびハンマーズ AR

大きなハンマーを持った小さなかわいいやつら（ちびハンマーズ）が、
ハンマーを**オートで**振り回して荒地や廃墟をこわし、**整地**していくスマホ向け AR3D ゲームです。

最初にカメラでまわりの景色を撮影すると、その写真を解析して荒地・廃墟の盤面をデザインします。

## 遊び方

1. 「はじめる」→ カメラでまわりを撮影（📷）。写真を選ぶ（🖼️）／おまかせ（🎲）でも OK
2. 写真から作られた「荒地レポート」とマップを確認して「整地スタート！」
3. ちびたちが勝手にハンマーを振ってこわしていきます
   - がれき・廃屋を**タップ** → そこを集中攻撃
   - ちびを**タップ** → 応援（しばらくスイングが速くなる）
   - こわすとコイン → 「なかま」「パワー」「スピード」を強化
   - ゲージがたまったら「フィーバー」でハンマーが金色に！
4. 整地率 100% でクリア。芝生とお花が咲いて次のレベルへ

## 写真 → 荒地のデザイン

撮影画像を 8×8 マスに分割し（写真の上 = 盤面の奥）、マスごとの特徴で置くものを決めます。

| 写真の特徴 | 置かれるもの |
| --- | --- |
| ごちゃごちゃ（エッジが多い）＋暗い 2×2 | 廃屋 |
| エッジ多め・暗い / 明るい | 崩れた壁・廃材 / がれき |
| 緑が多い | 草むら・枯れ木 |
| なめらかで明るい | 小石 |

さらに、写真の色を k-means で抽出したパレットで素材を色付けし、
写真そのものをくすませたテクスチャを廃墟の壁に貼り、空・地面の色からライティングを合わせます。

## AR 表示

- **カメラ AR（標準）**: カメラ映像の上に 3D の荒地ジオラマを重ね、ジャイロ（端末の向き）で空間に固定して表示。
  ピンチで拡大縮小、1本指ドラッグで回転、🎯で正面に戻す。ジャイロが無い PC ではドラッグで視点を回せます。
- **WebXR（対応端末のみ）**: Android Chrome など `immersive-ar` 対応端末では「床に置いて本格AR」で、
  現実の床を検出してタップした場所に荒地を置けます。

## 起動方法

ビルド不要の静的サイトです（three.js は `vendor/` に同梱）。カメラを使うため **HTTPS**（または localhost）で配信してください。

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

GitHub Pages でリポジトリのルートを公開すれば、スマホからそのまま遊べます。
